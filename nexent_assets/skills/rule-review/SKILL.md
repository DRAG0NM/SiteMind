# 规则复核

读取原文和定位，核对适用对象、触发条件、物理量、单位、边界、可见时间与生效时间；比对现行规则和标准原文。缺单位、对象、证据或存在无法解释的冲突时保留待处理，不补造事实。规划器规则优先参考同口径反事实损失，无法比较时标明不可比。

电价摘要可用 prepare_tariff_review 结合可见的节日日历生成待复核时段表；核对电网接入点、用电类别、假日日期、截止时间及原文定位，缺失时保留待定。

复核建议只能提交待确认动作，不能自行批准或发布。已复核候选仍不影响运行；由复核员确认发布后才激活新知识版本，已有运行保留原清单。
