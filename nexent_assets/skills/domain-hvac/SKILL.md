# 暖通领域要点

用 `read_skill_config` 读取 `config/config.yaml`（区域、舒适区间、动作词表、硬约束与汇报口径）。

## 判断顺序

1. 先看事件对象与所在区域：车间恒温区 22±2 ℃、行政楼 24～26 ℃；洁净车间 21～23 ℃ / 45±5 %RH，数据机房 18～27 ℃。
2. 洁净车间与数据机房是硬约束：不能停机、不能断供、不能改设定温度；削峰只能动行政楼这类非硬约束区域。
3. 动作词表固定：`set_mode`（normal / precool / off）、`set_setpoint`（`setpoint_c`）、`ventilate`（井道通风）。
   `precool` 表示设定温度比常规低 1 ℃、把冷量提前买进去；`off` 表示这段时间停供冷，温度会上浮。
4. 让出容量前先估温度：窗口内的温度上浮按区域热惯性估，别让室温越过舒适上限；越界分钟数就是提案代价 `comfort_min`。
5. 峰段让出的冷量要在窗口之后补回来：错峰不是省电，报“峰段少用多少 kW”，不要报成“省了多少电”。

## 汇报口径

一到三句中文，先结论后依据：先报“动哪个区域、动多久、让出多少 kW、室温到多少”，再报依据（区域参数或事件单）。
数值只引用 `plantkg_hvac_propose` 返回的 `proposal_id` 与摘要，不自己编温度、功率和省钱数。
