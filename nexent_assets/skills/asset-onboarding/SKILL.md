# 资料入库

先按资料类型模板批量抽取并保留原文定位。只有判别门控通过、对象存在、标准对齐且无冲突的条目走流程段；其他条目进入例外调查。

调查时查图谱对象、新旧资料的版本与生效日期及适用标准的原文。区分标准对安全或程序的要求与手册自行规定的数值；没有原文、适用范围或有效日期时明确待定。需要现场事实时最多询问值班人员一个问题。给出合并、替代、补节点或待定的建议和精确来源；建议不是发布。

人工复核结果回写本类型示例、别名、字段映射和判别校准样本。候选只有经统一发布流程和人工确认后才能影响图谱或专家行为。
