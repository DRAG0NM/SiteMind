# 电梯维护保养手册（厂内版，2026）

> 性质 synthetic：按常理编写的厂内维护手册；引用的铭牌参数与实物照片一致。

## 3.1 日常保养

每日检查层门开关是否顺畅、门锁触点是否氧化；每周检查曳引机运行声音、油位与温升；每月测试应急照明与对讲。

## 3.2 困人救援

接到困人报警后 3 分钟内确认轿厢停靠楼层与被困人数；立即通知维保单位并安抚被困人员。
救援由持证人员按盘车规程执行，系统不得自动操作故障电梯；救援完成后填写《困人救援记录》。

## 3.3 曳引机与门机

检查曳引机运行声音、油位与温升；检查门机皮带松紧与开关门时间。
门机电机铭牌参数为额定 0.37 kW、230/400 V、1.67/0.97 A、2730 r/min、防护 IP55、绝缘 F 级，更换须同型号。

## 3.4 限速器与安全钳

每两年校验一次限速器动作速度；安全钳动作后必须拆检并复位，复位后做空载与满载试验。
