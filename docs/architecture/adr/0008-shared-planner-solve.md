# ADR-0008 共享规划器的整数能力、超时与校验规则

- 状态：B09 提出（2026-10-30），随 B09 PR 复审
- 影响分支：B09、B10、B11、B12、B13、B15、B17、B28
- 依据：ADR-0001（MILP、单一模型）、04「规划模型契约」、契约 `SolverStatus`

## 决定

1. **模型能力**：`add_var` 支持 `continuous / binary / integer` 三种 domain。默认按时间集合建索引；`scalar=True` 建标量，`index=[s…]` 只为给定时段下标建变量（空集合直接拒绝，不退化成标量），满足 ADR-0001 中“工序只为能完整放进窗口的开始时段建 x[s]”的要求。储能充放互斥由 B11 用二进制 `u[t]` 自己建约束，规划器不内置互斥逻辑。
2. **隔离**：变量和约束名加 `{pack}__` 前缀；登记约束、平衡项和成本项时，检查表达式里的变量只能是本包变量或公共 `grid_import/grid_export`，否则拒绝。平衡项中的连续变量必须是 kW。
3. **唯一目标**：只有 `finalize` 生成目标（各成本项之和）和公共功率平衡；包不能设目标或求解参数。
4. **超时**：
   - 触及时间或迭代预算且求解器给出可行解时，返回 `feasible`，附实际 gap = |目标 − 下界| / |目标|；
   - 没有可行解时返回 `timeout`，不带计划；
   - 不会为了出解延长预算或放宽 gap，后台任务的预算由调用方（JobRunner，ADR-0006）决定。
5. **独立校验**：有解时先取整、置零，再校验有限性、上下界、整数性（1e-6）和全部约束（相对 1e-5）；任一项不通过返回 `error`，不带计划。目标值用取整后的解重新计算。
6. **不可行**：返回 `infeasible`，第一条线索固定写明“不是 IIS”。后面附上逐包停用约束后重新求解的结论，用于提示哪些包参与了冲突。重新求解只为诊断，结果不会生成计划。
7. **规则闭环**：规则编译器只声明约束名；包建完约束后由规划器核对“声明的约束存在、属于该包、带该规则的 Ref、至少一条”。对不上返回 `error`。不在规划区间内生效的规则直接跳过；不可见、未审核或无编译器的规则作为 `PendingIssue` 返回。
8. **线程**：HiGHS 进程内锁定首次求解的线程数，实际值记入 `SolverInfo.params["threads_effective"]`。
9. **词典序第二阶段**：第一阶段只最小化原费用；第二阶段把原费用限制在第一阶段的值以内（只放宽 max(1e-6, 1e-7×|费用|)），再最小化购电，避免零电价时段出现“弃光同时购电”的等价解。下界和 gap 取第一阶段的，第二阶段不会让原费用变差，所以下界仍然有效。有可行解但没有有效下界时返回 error（纯 LP 最优除外）。第二阶段固定整数变量后按 LP 求解，预算 max(剩余, 0.5 s)；原费用为常数时不加上限；失败时回退到第一阶段的解。无论解来自哪个阶段，返回前都按 B08 口径核对“弃光（Plan 中 `pv_curtail` 动作）同时购电”，不通过返回 error。只核对这一条，其余账本规则由 B08 判定。第二阶段结果记在 `SolverInfo.params["stage2"]`。
11. **并发**：求解器调用（版本探测、求解、结果加载）在进程级锁内串行执行；`time_limit_s` 只约束拿到锁之后的求解，排队时间另记。
12. **规则取回**：请求的规则必须全部取回，漏取、多出或重复都拒绝。
10. **诊断预算**：冲突诊断的总预算是原预算的一半，`elapsed_s` 包含诊断耗时。

## 理由

- 只靠求解器状态码不足以保证计划可执行，取整和置零也可能破坏等式，所以必须独立校验。
- 伪造 IIS 会误导复核员；逐包停用约束的成本低，结论可以复现，而且明确只作为线索。
- 跨包变量检查让“包只经 ModelBuilder 贡献”在运行时可验证，不只停留在约定。

## 测试

`tests/planner/test_planner.py` 覆盖以下场景：
- 两种贡献顺序结果一致；
- 无可行解超时、有可行解超时（真实 HiGHS 多维背包）；
- 求解器自报 optimal 但取值错误时返回 error；
- 小数二进制值和越界被独立校验拦下；
- 规则声明的约束缺失时返回 error；
- 跨包读变量、平衡项单位错误、约束缺少 Ref 时拒绝；
- 绕过 builder 加组件、改公共变量上下界时拒绝；规则约束全部跳过时返回 error；
- 同一进程内切换线程数仍能求解；零电价时段与外送大于 0 时，只凭 Plan 复算的 B08 账本平衡；
- 计划通过 B08 计划账本校验。
