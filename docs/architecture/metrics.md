契约版本：B01 v1（2026-10-30 起草，B01 合并即冻结；改动走契约前置变更）

本表登记初赛要求“方案最终达到的效果”的全部量化指标：定义、产出分支、数据集与划分、对照组、出数日期。指标在 11-25 冻结前出数；真实 Nexent 与 Mock 结果分开报告，无收益、失败、无解也如实报告，不设预定通过线。测试集与校准/评分日不重叠，划分与容差在冻结前预登记。

**约定**

- 出数日期按路线图关口：G2 一日闭环 11-10，G3 核心链路 11-17，其余 ≤ 11-25。写两个日期的，前者为首个数、后者为终值。
- 评测日：独立评测日，各对照组统一 E[0] = E_ref、期末要求相同；日期、数量未选定（07 Q18），待 B18/B32 开工时预登记。候选验证日、评分日、最终测试日三者互不重叠。
- 能源数据：HIPE 一周（measured，负荷倍数 configured）、PVGIS（derived）、省级分时电价政策（B12 选定，候选江苏 2025 新版，原文待核）、储能与工序功率（configured）。

- 指标由账本、评测模块计算，不由 LLM 打分。
