# B30 资料入库与规则发布

在仓库根目录运行 `python -m plantkg.knowledge.rules`。离线演示接入 B26 的新旧空压资料和 synthetic 行政楼规范，显示冲突、来源、人工复核、发布前后版本、暖通动作与模拟泄漏研判。Agent 回答与复核员操作是明确标注的离线替身，不代表 Nexent 实跑或真人复核。规程的适用性示例假设主管公称直径为 80 mm（configured）；TSG 摘录及来源见 `fixtures/tsg31-2025-excerpt.md`。泄漏阈值来自 synthetic 厂内手册，而非 TSG 规程。

`extract_rules` 从 B06 的内容快照抽取候选，当前模板覆盖明确单位的主管压降、`区域温度中心±偏差`和电梯拥堵触发条件；政策时段先抽取季节时段并列出缺项，复核员须补齐时段表与可见的节日日历资料引用，通过 B12 校验后才可提议发布。`propose_review_decision` 只提出待确认动作，复核员通过 B04 确认后 `compile_reviewed_rule` 才能编译；`KnowledgePublisher` 兜底将候选交给另一次人工确认，确认后 B04 才激活版本清单。兜底**不回测**，等待 B32 实现替换。全部规则集需包含要继续保留的既有规则。

本体候选用离线字符二元组向量做余弦召回，未命中或并列时标为规则召回并转人工；它不是嵌入模型，召回覆盖率未知。`shapes.ttl` 与检查器实现当前使用的 SHACL Core 子集（`targetClass`、`property`、`path`、`minCount`），仅检查结构。图写入 B03 版本化命名图，旧运行固定旧清单；候选与复核决定保存在本地数据库中。

使用与知识服务共用数据库的场景注册表时，资料上传只登记候选，不直接加知识标签；复核员确认并发布包含该资料规则的清单后，场景下一步分叉至新版本。未装服务接缝的旧版独立场景仍使用 B17 的标签替身。学习日志记录复核后的类型、示例、别名、字段映射及校准样本；实际使用的 token、人工分钟和耗时须按批次实测填入，不能把模拟演示耗时当真人指标。

`record_onboarding_batch` 由复核员登记已确认候选的实际分钟、token 和耗时，并保存批次候选、Agent 分流比例及标准对齐率；标准对齐按可见资料版本和复核员给出的条款定位统计，不代表自动验证标准适用性。同一批次重复登记必须内容一致。

候选可以再次提出复核并经确认更正；旧决定及对应动作保留，新的别名与字段映射另存为学习样本，已发布版本不会被改写。

`process_onboarding` 先抽取并分流，只把例外候选交给 `investigate_onboarding` 的 B04 后台任务；场景上传使用同一入口。调查固定当前知识版本并提供新旧资料、日期和已对齐标准原文；通过 B23 Nexent 网关生成带资料引用的调查建议，替代建议必须引用旧资料并逐字核对标准引文。没有网关时使用明确标为 synthetic 的确定性替身：仅对合成新旧资料，在识别到较新的生效日期与可核对的泄漏检查原文时建议替代，否则待定；都必须人工复核。调用方可通过 `onboarding_investigations` 读取结果。这两个提交接口不向 Agent 暴露，避免递归启动调查；测试使用网关替身，尚未实调模型。

`score_review_candidate` 使用后台任务和评分日提供者；电价比较器调用 B09 对同一预测求解 A/B，再用 B08 与 B 的电价重算 A、B 成本。评分与知识版本绑定，换版本后不会沿用旧分数。`mock` 配置下显式传入 `{"synthetic_demo": true, "peak_ratio": 1.1}` 可跑合成示例：预测、校准样本、划分与概率均标为 synthetic，不代表真实校准。缺少真实冻结评分数据及备选解释校准概率时只登记未校准、排队优先；非电价规则还没有相应比较器。

工单挖掘落成 B06 候选资产后，可通过 `extract_rules` 进入 B30，原工单引用随候选保留；B30 兜底发布器不接收旧工单格式，B26 在同时提供资产落库器时会保存候选资产。复核员补齐事件、观察条件、处置建议和适用实体后，可编译为维保建议并经人工确认发布；设备专家仅在事件对象、类型和观察文本匹配时附上建议及规则依据，不凭工单建议自动下发动作。

政策摘要可以抽出峰、平、谷和尖峰时段及浮动比例；`prepare_tariff_review` 读取单独的可见日历资料（文本行格式为 `春节：日期、日期`、`五一：日期、日期`、`国庆：日期、日期` 和 `登记至：YYYY-MM-DD`），生成待复核的完整时段表。解析采用 `Asia/Shanghai` 作为实施选择；人工须核对日期覆盖范围、适用类别和原文。复核、发布确认后，接入知识服务的场景分钟账本、冻结试算输入和能源重算使用新电价，旧版本保持原值。

电梯楼层区间可抽取、复核并入规则，运行分区仍取 B20 既有配置，配置与已发布区间不一致时暂停自动分区。真实校准与真实环境联调仍需其各自的数据和服务。
